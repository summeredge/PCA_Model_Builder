# 模型包契约

## 当前与后续状态

当前模型包为 schema v3，使用 `manifest.json` 和 `arrays.npz`，不包含原始过程数据且不使用 pickle。其实际语义支持 `exploratory / draft`、`normal_state / candidate` 和 `normal_state / validated`；schema v1/v2 继续只读加载。schema v3 尚未实现正式冻结模型包、部署评分参考实现或部署一致性测试。

后续冻结模型包预计以新的 schema 演进实现，不在本 PR 修改 schema。新 schema 必须保留旧 schema 的兼容策略，且冻结模型包不得包含原始生产数据。

## 未来冻结模型包字段分类

冻结模型包必须包含以下可检查字段：

- 模型标识：模型名称、修订号和 schema 版本；
- 创建与冻结：创建信息、冻结信息和工程师结论；
- 适用范围：适用装置、单元和工况；
- 输入契约：输入 Tag、固定顺序、描述、单位和采样周期；
- 预处理契约：完整预处理参数、物理缺口识别与重置规则；
- 动态特征：名称和固定顺序；
- PCA 参数：均值、标准差、载荷、特征值、解释率和主元数；
- 控制限：T² 95%/99% 控制限及 SPE 95%/99% 控制限；
- 评分契约：状态判定规则和不可评分规则；
- 贡献契约：T²/SPE 分别计算的贡献规则、触发规则、Tag 聚合规则和贡献百分比规则；
- 训练证据：训练窗口和训练摘要；
- 验证证据：验证窗口和验证摘要。

字段顺序是计算契约的一部分：输入 Tag 和动态特征均不得由部署端重新排序或推断。
